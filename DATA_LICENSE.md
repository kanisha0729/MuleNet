\# Data attribution and license



This project uses the IBM "Transactions for Anti Money Laundering (AML)" dataset

(HI-Small version). It is a synthetic dataset generated to simulate money laundering

patterns and contains no real customer data.



\- Dataset: https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

\- Paper: Altman et al., "Realistic Synthetic Financial Transactions for Anti-Money

&#x20; Laundering Models" (NeurIPS 2023), https://arxiv.org/abs/2306.16424

\- License: Community Data License Agreement - Sharing, Version 1.0 (CDLA-Sharing-1.0),

&#x20; https://cdla.dev/sharing-1-0/



The full dataset is not included in this repository. Download it from the link above.



results/results.csv is a modified subset of that dataset (sampled rows, with model

output columns added), and is shared under CDLA-Sharing-1.0.
